# Английский по кайдзену

Сайт с 43 ежедневными уроками английского с 19 ноября по 31 декабря 2026 года. Курс начинается со знакомства и бытовых ситуаций, затем переходит к рабочему английскому и пробному собеседованию на позицию frontend-разработчика.

## Запуск

Распакуй архив и открой `index.html` в браузере. Все четыре файла сайта должны лежать в одной папке. Установка зависимостей и сборка не требуются.

Если нужен запуск через локальный HTTP-сервер, выполни в папке сайта:

```bash
python3 -m http.server 8000
```

Открой [http://localhost:8000](http://localhost:8000).

## Как проходить уроки

1. Выбери дату в календаре. Кнопка «Сегодня» доступна в даты курса и учитывает часовой пояс Еревана.
2. Нажми «Послушать», чтобы услышать английскую фразу. Озвучка зависит от доступности английского голоса в браузере.
3. Введи перевод с русского на английский и нажми «Проверить». Сайт сравнивает ответ с образцом с учётом нормализации регистра и пунктуации. Другие формулировки тоже могут быть правильными.
4. Выполни задание из раздела «Практика вслух». В отдельных уроках доступны пять вопросов для пробного интервью.
5. Отметь урок выполненным. Чтобы отменить отметку, нажми «Снять отметку».

Отметки хранятся в `localStorage` текущего браузера. Прогресс привязан к адресу сайта и профилю браузера. Поддержка хранения при открытии напрямую через `file://` зависит от браузера. Для стабильного локального адреса используй HTTP-сервер.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка календаря, урока и упражнений |
| `style.css` | Оформление и адаптивная раскладка |
| `lessons.js` | Темы уроков, фразы, переводы и задания |
| `app.js` | Выбор урока, проверка перевода, озвучка и сохранение прогресса |

## Развёртывание

Загрузи все четыре файла в одну папку статического хостинга. Точкой входа служит `index.html`.
