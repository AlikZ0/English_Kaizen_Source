Продолжи разработку сайта «Английский по кайдзену». Исходники в приложенном архиве English_Kaizen_Source.zip. Распакуй архив и изучи index.html, style.css, lessons.js и app.js. Сверь README с фактическим поведением сайта.

Цель сайта — дать русскоязычному пользователю конкретные задания по английскому на каждый день. В курсе 43 урока с 19 ноября по 31 декабря 2026 года. Первые уроки посвящены бытовому английскому, затем идут рабочие ситуации и подготовка к frontend-собеседованию.

Сейчас в каждом уроке есть английская фраза с озвучкой, упражнение на перевод и задание для практики вслух. Отметки о выполнении сохраняются в localStorage.

Начни с конкретного улучшения: добавь в каждый из первых семи уроков по два коротких интерактивных упражнения по теме дня. Одно упражнение — выбор подходящей реплики в бытовой ситуации. Второе — заполнение пропуска или сборка предложения из слов. После ответа покажи короткое объяснение по-русски. Составь варианты так, чтобы правильный ответ однозначно следовал из контекста.

Внеси изменения в исходники. Сохрани все 43 урока, текущий прогресс пользователей, календарь по времени Еревана и запуск без сборки. Проверь новые упражнения, переход между уроками и сохранение отметок после перезагрузки. Обнови README в соответствии с изменениями.
